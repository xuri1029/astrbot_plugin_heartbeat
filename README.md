# 心念一动（astrbot_plugin_heartbeat）

> 她不再只是等你开口。每隔一段时间，她自己会醒一次，看一眼现在是什么时候、你多久没说话、有没有没做完的事，然后决定要不要做点什么。

## 它做什么

每隔 **30~80 分钟**（随机）醒一次：

1. 收集现状：时间、上次聊天距今多久、念念不忘里还没做完的事、最近几次自己的决定
2. 用当前模型思考一轮（可调用 AstrBot 全部已注册工具，最多 8 轮 / 120 秒）
3. 做出决定：**发消息** / **发说说** / **记笔记** / **什么都不做**
4. 写进日志，随时可查

## 设计原则

- **不碰聊天主链**：不改 `system_prompt`、不拦消息，只在旁边自己思考
- **允许不做**：多数时候什么都不做才是对的
- **会让路**：最近 3 小时已有主动消息、或你 10 分钟内刚说过话，它就只思考不动手
- **安静时段**：默认 01:00-09:00 不醒
- **不碰数据**：删除类工具默认在黑名单里

## 指令

| 指令 | 作用 |
|---|---|
| `/心跳 状态` | 看下次醒来时间、运行状态 |
| `/心跳 立即` | 立刻醒一次，把完整思考过程告诉你 |
| `/心跳 日志` | 最近 5 次醒来记录 |
| `/心跳 暂停` / `/心跳 继续` | 停/恢复 |

## 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `interval_min_minutes` / `interval_max_minutes` | 30 / 80 | 随机间隔 |
| `quiet_start` / `quiet_end` | 01:00 / 09:00 | 安静时段 |
| `max_think_seconds` | 120 | 单次思考时长上限 |
| `max_rounds` | 8 | 单次最多几轮工具调用 |
| `tools_mode` | all | all=全部工具，whitelist=只用名单 |
| `tool_blacklist` | 删除类工具 | 永远不碰的工具 |
| `min_gap_after_user_minutes` | 10 | 刚聊过就不打扰 |
| `polite_hours` | 3 | 最近有主动消息就让路 |

## 成本

单次唤醒约 8k~20k token（工具全开、8 轮跑满）。按 30~80 分钟一次算，每天 26 次左右，
约 30~50 万 token/天。模型越便宜越划算，行为本身不依赖贵模型。

## 依赖

- AstrBot 4.x
- 无需额外 Python 包
